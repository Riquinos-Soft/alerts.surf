## MODIFIED Requirements

### Requirement: Landscape hero and value proposition
The platform SHALL render an engaging, bright, accessible hero section with realistic surf photography, interactive 3D wave or ocean canvas effects, and unified mobile-first Vant UI controls.

#### Scenario: User visits the platform root
- **WHEN** a user navigates to the root URL `/`
- **THEN** the application renders the light-themed hero section with 3D ocean animation, crisp surf branding, and call-to-action buttons styled with Vant UI

#### Scenario: Viewport size changes
- **WHEN** the viewport transitions between mobile, tablet, and desktop dimensions
- **THEN** the hero layout adapts fluidly while keeping the 3D canvas and realistic imagery responsive and performant

### Requirement: Interactive feature and vision showcase
The welcome page SHALL present key product pillars and forward-looking capabilities with realistic imagery, an interactive mobile app mockup demonstrating live surf conditions, and component carousels using Vant UI.

#### Scenario: Reviewing core forecast capabilities
- **WHEN** a user explores the product showcase
- **THEN** the interface displays clear cards and interactive app mockup screens illustrating wave height, swell period, wind direction, and spot scoring

#### Scenario: Reviewing future agentic assistant vision
- **WHEN** a user reviews the intelligent assistant section
- **THEN** the interface highlights the voice and conversational quiver management vision inside the interactive app preview with realistic gear imagery

#### Scenario: Reviewing transparent pricing
- **WHEN** a user views the pricing section
- **THEN** the interface highlights accessible pricing tiers with clean, bright card styling and Vant buttons
